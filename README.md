# FML-Assignment

## How to run
1. Download the dataset from https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008 and put `diabetic_data.csv` and `IDS_mapping.csv` in `Data/`.
2. `pip install -r requirements.txt`
3. Run the notebooks in order: `data_desc` → `preprocessing` → `logistic_regression` → `random_forest` → `comparison`.
   The `models/` folder and `Data/processed/` are created by the notebooks and are not stored in Git.
